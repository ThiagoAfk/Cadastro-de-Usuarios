# Cadastro-de-Usuarios
Projeto pessoal desenvolvido em Python com o objetivo de praticar lógica de programação e organização de código.

Funcionalidades
Cadastro de usuários com identificador único (ID)
Listagem de usuários com status
Exclusão de usuários por ID
Persistência de dados utilizando arquivo JSON
Tratamento de erros e validação de entradas
Menu interativo via terminal
